Maple now keeps an append-only **audit log** for every organization. It records each action taken in Maple from the dashboard, the public API or MCP, whether it was allowed or denied, along with every read of telemetry and session replays. Each entry names the user, API key or agent that performed it.

This gives you a record for security reviews and compliance audits: who changed an alert rule, which API key queried logs, or which agent read a session replay.

Admins find it under **Settings → Audit Log**. You can filter by actor type and outcome, see the reason for denied actions, and open an entry to see what changed, with before and after values. The same entries are available from the API at `GET /v2/audit_log` with an API key that has the `audit_log:read` scope. Entries are kept for six years.

See [Data retention](/docs/reference/retention) and the [API reference](/docs/reference/api).
