# @maple/landing

The Maple marketing site and documentation (maple.dev), built with Astro and deployed as a static-asset Worker.
Run it with `bun dev landing` (in the stack, `https://landing.localhost`) or `bun --filter=@maple/landing dev` (alone, `http://127.0.0.1:3391`, override with `PORT`).
Docs content lives in `src/content/docs/`; the blog, changelog, customers and roadmap collections sit beside it in `src/content/`.
Design rules for the site are in `DESIGN.md`.
