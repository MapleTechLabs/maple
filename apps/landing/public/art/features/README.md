# Feature illustrations

Nine original illustrations generated with the built-in GPT Image Gen tool, using `../maple-rome-balanced.webp` as the shared style reference. Each uses amber-on-charcoal Roman engraving and medium-fine ordered dithering. WebP delivery copies are 1536 × 1024; each adjacent `*-prompt.md` records the full prompt and concept.

| Feature | Illustration | Connection |
| --- | --- | --- |
| Distributed tracing | [Aqueduct channels](distributed-tracing.webp) | Follow a journey through branching infrastructure. |
| Browser sessions | [Roman theater](browser-sessions.webp) | Replay a sequence of events. |
| Log management | [Archive](log-management.webp) | Organize and retrieve recorded events. |
| Metrics and dashboards | [Water clock](metrics-dashboards.webp) | Measure changes over time. |
| Service catalog | [Connected forum](service-catalog.webp) | Understand distinct services and their connections. |
| Error tracking | [Cracked keystone](error-tracking.webp) | Locate the fault within a larger system. |
| Alerts | [Signal tower](alerts.webp) | Recognize a warning and act on it. |
| AI / MCP integration | [Scholar's instrument](ai-mcp-integration.webp) | Access connected knowledge through a common interface. |
| Kubernetes monitoring | [Organized harbor](kubernetes-monitoring.webp) | Oversee coordinated workloads and infrastructure. |

The feature registry selects the image for the shared `PageHero` component in all three locales. Art is decorative, placed behind the right side of the header and faded away from the copy. Mobile reduces its opacity so headings and controls remain readable. Product screenshots retain their original appearance.
